# FinalProject-_Military-Soldier-Safety
This project uses the YOLOv11 object detection model to automatically identify and classify military and civilian objects in real time. It detects threats such as weapons, enemy soldiers, and vehicles while distinguishing friendly forces and civilians.
Project Description

This project focuses on enhancing situational awareness and ensuring soldier safety in modern military operations through automated threat detection. Using YOLOv11, a state-of-the-art real-time object detection model, the system is trained on a curated dataset containing military and civilian scenarios. It detects and classifies objects such as soldiers (friendly and enemy), weapons, military vehicles, civilian entities, and trenches.

The goal is to develop an intelligent computer vision system that:

Detects threats in real time, including weapons and enemy combatants.

Differentiates between military and civilian entities to minimize errors and ensure ethical engagement.

Enhances battlefield awareness by tracking multiple object types in diverse environments.

Improves soldier safety by providing early warnings of potential threats.

To make the results interactive and easy to interpret, the system is integrated with Streamlit, enabling real-time visualization of object detection outputs, performance metrics, and live video inference through a user-friendly web interface.

By leveraging YOLOv11’s accuracy and Streamlit’s visualization capabilities, this project delivers a robust, efficient, and scalable solution for automated surveillance and decision support in defense applications.
